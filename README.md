# Analyse 1 — cours expliqué

Cours d'Analyse 1 (L1 MIDO, poly p. 1 à 35) expliqué en détail, et une liste de vidéos YouTube pour réviser.

- **Ouvrir le cours :** https://picascience.github.io/cours-analyse/
- **Vidéos :** https://picascience.github.io/cours-analyse/videos.html

## Sur iPhone
1. Ouvre le lien dans **Safari**.
2. Touche **Partager** (carré avec une flèche) → **Sur l'écran d'accueil** → **Ajouter**.
3. L'icône « Analyse 1 » apparaît : elle s'ouvre en plein écran comme une app, et marche même sans connexion après la première ouverture.
